# TrueGuard ecosystem logo drop zone

Place transparent SVG or PNG files here using these names:

- `x-layer.svg`
- `okx.svg`
- `okx-wallet.svg`
- `okx-onchainos.svg`
- `spacex.svg`
- `tesla.svg`
- `backed-xstocks.svg`
- `paxos.svg`
- `pax-gold.svg`
- `chainlink.svg`

The frontend keeps a text fallback visible when a logo file is missing. Logos do not imply a partnership; each item is labelled by its actual relationship to TrueGuard.

Current sources:

- X Layer mark: a clean vector recreation of the five-square X used by X Layer.
- OKX, SpaceX, Tesla and Chainlink marks: Simple Icons SVGs, used only to identify the named source or integration target.
- xStocks mark: the official xStocks media and brand kit.
- Paxos and PAX Gold marks: the official Paxos brand-resources page.
- `okx-wallet.svg` and `okx-onchainos.svg` use the OKX master mark because both products sit inside the OKX product family.
